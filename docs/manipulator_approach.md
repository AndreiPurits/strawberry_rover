# Подход манипулятора к выбранной ягоде

Способ относится к бортовому сбору клубники при камере, установленной на манипуляторе (eye-in-hand). Вход — выбранная спелая ягода и оценка расстояния по маске (`pipelines/strawberry_ensemble.py`). Выход — положение манипулятора на рабочей дистанции (standoff) с сохранением идентичности цели. Точка реза по плодоножке рассчитывается отдельно (`pipelines/peduncle_grasp/`).

Код: `pipelines/arm_approach/`  
Конфиг: `config/arm_approach_v1.yaml`  
Геометрия: `scripts/arm_approach_geometry.py`

## 1. Исключение клешней

В нижней части кадра задаются две горизонтальные поисковые полосы в местах клешней захвата. В каждой полосе выделяется тёмная связная область ограниченной ширины. Полученные прямоугольники исключаются из детекции и из оценки яркости.

Поиск по фиксированным полосам исключает слияние клешней с тёмной перемычкой или тенью по всему низу кадра.

Код: `pipelines/arm_approach/claw_exclude.py`.

## 2. Фиксация цели (lock)

Среди детекции выбирается ягода, ближайшая к предыдущей позиции (штраф за пространственный скачок, ограничение максимального смещения). При установленном lock повторный вывод выполняется сначала в ROI вокруг последней позиции; полный кадр — только при отсутствии цели в ROI.

При кратковременной потере детекции сохраняются последние координаты и глубина (hold). Цветовая эвристика зрелого пятна не образует самостоятельной цели и учитывается только совместно с детекцией модели.

Код: `pipelines/arm_approach/tracker.py`.

## 3. Одношаговый подход

По зафиксированной цели `(px, py, depth)` и текущим суставам:

1. Среди успешных демонстраций выбирается ближайшая в пространстве суставов, положения ягоды на кадре и глубины.
2. Приор движения — приращение суставов этой демонстрации `Δq`.
3. Остаток ошибки относительно целевого изображения и рабочей глубины проецируется через локальный якобиан 3×3  
   `[dpx, dpy, ddepth] ← [dshoulder, delbow, dbase]`.
4. Решение — взвешенный метод наименьших квадратов с регуляризацией к приору и ограничением величины коррекции, чтобы уточнение не подменяло демонстрационное перемещение.
5. Выполняется **одно** перемещение в пространстве суставов.
6. Проверка: ягода сохранена в кадре, глубина в полосе standoff, глубина уменьшилась, смещение на изображении согласовано с командой.

При отсутствии якобиана используется запасной закон центрирования по оси основания.

Код: `pipelines/arm_approach/planner.py`, `pipelines/arm_approach/verify.py`.

## 4. Фазы CENTER и REACH

Зависимый режим визуального серво:

- CENTER — совмещение горизонтали цели с заданным направлением при сохранении вертикали lock (`lock_y`).
- REACH — согласованное изменение плеча и локтя к рабочей глубине с нижним ограничением (depth floor).

При уходе цели по горизонтали сверх допуска управление возвращается в CENTER.

Код: `pipelines/arm_approach/phases.py`.

## 5. Вариант: декартово визуальное серво

По малым фактическим смещениям рабочего органа оценивается матрица `M`: `Δcam = M · Δtip`. Управление: `Δtip = M⁻¹ · (цель − текущее)` при ограничении рабочей зоны и запрете захода глубже standoff. Проекция ожидаемого пикселя используется для повторного захвата lock после большого хода.

Код: `pipelines/arm_approach/cartesian.py`.

## 6. Откат при потере цели

При потере lock манипулятор возвращается по сохранённой истории положений до повторного появления ягоды в кадре, после чего подход возобновляется.

Код: `pipelines/arm_approach/rollback.py`.

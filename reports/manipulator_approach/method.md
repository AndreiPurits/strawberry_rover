# Подход манипулятора: метод и проверка

Onboard: камера на манипуляторе, выбранная ягода после ensemble, планирование без операторского слоя.

- Код: `pipelines/arm_approach/`
- Конфиг: `config/arm_approach_v1.yaml`
- Описание: `docs/manipulator_approach.md`

## Вход

- детекции ягод на кадре камеры манипулятора (`x1,y1,x2,y2,conf`);
- карта глубины, выровненная с RGB;
- текущие суставы `base`, `shoulder`, `elbow`;
- набор успешных демонстраций (суставы и ягода до/после хода);
- локальный якобиан 3×3 либо его отсутствие.

## Последовательность

Исключение клешней → lock → план одного хода → (исполнение вне этого пакета) → проверка standoff.

Исполнение команд манипулятора в объём данной ветки не входит.

## Проверка standoff

Успех, если одновременно:

- ягода присутствует после хода;
- координаты в рабочей области кадра;
- глубина в полосе standoff;
- глубина уменьшилась относительно lock;
- при заметном ходе суставов изображение или глубина изменились.

Иначе — отказ с перечнем причин (`low_conf`, `out_of_frame`, `depth_not_in_standoff`, `insufficient_depth_progress`, `suspicious_no_image_motion`).

## Ограничения реализации

- планирование по трём суставам (`base`, `shoulder`, `elbow`);
- одно движение на цикл планирования;
- точка реза по плодоножке — отдельный контур `pipelines/peduncle_grasp/`.
